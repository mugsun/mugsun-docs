# Core 概述

[mugsun-core](https://github.com/mugsun/mugsun-core) 提供 BOM 与少量 starter（如 Web、MyBatis），供 boot 与其它模块复用。

- 一般业务集成从 [boot](/boot/) 开始即可。
- 构建 boot 前须将本仓与 boot **平级**克隆，并执行 `mvn clean install -DskipTests`（尚未发布到 Maven Central）。
- Starter 列表与版本坐标以仓库 README 为准。
