# 埋点概述

mugsun track 是**嵌入式**产品分析能力：浏览器 SDK 采集 → boot track 域摄入 → pc 看板，随私有化部署带走。

- SDK：[mugsun-track](https://github.com/mugsun/mugsun-track) / npm `@mugsun/track-web`
- 定位对标「轻量 + 可自托管」叙事（如 Plausible 的体积与隐私意识），**不是**公有云分析 SaaS
