# 导入已有表

数据库里已经有业务表时，在「系统管理 → 代码生成」里导入它，再按需调整字段配置。

## 导入

1. 在「生成数据源」里选主数据源，或选一个已登记的数据源。
2. 在「数据表」里选表，填写模块、基础包、前缀和作者。
3. 点「导入」。

导入时系统读取表的列，推断 Java 类型和控件，生成一份表配置。删除表配置不会删除数据库里的表。

同一张表再次导入时，配置按当前库结构更新，改过的字段配置会保留。表结构变了之后，也可以在列表里点「同步」。

## 生成数据源

「系统管理 → 生成数据源」可以登记多套数据库。保存时系统会尝试连接，口令保存后不再显示。连上的数据源才会出现在代码生成的下拉框里。

## 生成方案

「系统管理 → 生成方案」保存一套模块、基础包、表前缀和作者。启用一套方案后，导入表时会自动带上这些值，仍然可以在导入前修改。

## 字段配置

在列表里点「配置」，可以改模板和每个字段的设置：

- 模板：单表、树表（需要指定父字段）、主子表（需要指定子表和外键列）。
- 字段：Java 类型、注释、控件、字典码，以及是否出现在列表、表单和查询条件里。

## 看效果

导入或通过建模确认一张表后，点这一行的「配置」，会打开字段配置窗口。

![字段配置](/screenshots/codegen/gen-config.png)

改完点「保存配置」，预览和下载都会使用这份配置。
