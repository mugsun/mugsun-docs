# 代码生成

代码生成把一张表的结构变成后端实体、Mapper、控制器，以及管理台列表页、接口文件和菜单 SQL。

## 选一个入口

| 已有什么 | 用哪个入口 | 页面 |
| --- | --- | --- |
| 只有一个想法，还没有表 | [AI 辅助建模](./ai-modeling) | 系统管理 → 动态建表 |
| 数据库里已经有业务表 | [导入已有表](./import) | 系统管理 → 代码生成 |
| 表配置已经调好 | [预览和下载产物](./output) | 系统管理 → 代码生成 |

两条路最后都落到同一份表配置上。在动态建表里确认过的表，会直接出现在代码生成的列表里。

## 权限码

| 权限码 | 用途 |
| --- | --- |
| `sys:gen:list` | 查看库表、表配置，生成建模候选 |
| `sys:gen:import` | 导入已有表 |
| `sys:gen:edit` | 保存字段配置、同步表结构、删除表配置 |
| `sys:gen:preview` | 预览代码、预览 DDL、下载 zip |
| `sys:gen:ddl` | 确认建模、建表、同步物理表 |

管理员持有全部权限码。其他角色要在菜单管理里勾选「代码生成」下的按钮。

## 看效果

用管理员登录管理台，打开「系统管理 → 代码生成」，能看到库表选择框和已导入的表配置列表。
