# 表单

mugsun 有两种表单。表单设计用拖拽的方式做表单，填报数据单独保存。在线表单直接读写一张业务表，不生成代码。

## 能干什么

- 「表单设计」基于 form-create 设计器，拖拽字段、设置校验，保存为一份表单定义。
- 表单定义可以单独用于填报，也可以绑定到[工作流](./workflow)的节点上。
- 「在线表单」读取代码生成里导入的表配置，按配置渲染列表、查询条件和编辑表单，增删改直接落到业务表。

## 怎么开

两种表单都随后端一起启动。在线表单要先在[代码生成](/boot/codegen/import)里导入业务表。

## 怎么用

表单设计：

1. 打开「系统管理 → 表单设计」，新建表单，填写名称和表单标识（`formKey`）。
2. 拖入字段，保存。
3. 前端按 `GET /system/form/by-key/{formKey}` 取表单渲染。
4. 用户提交时调用 `POST /system/form/submit-data/{formKey}`。

在线表单：

1. 在代码生成里导入一张表，在「配置」里设置哪些字段出现在列表、表单和查询条件中。
2. 打开「系统管理 → 在线表单」，选择这张表，即可增删改查。

## 注意点

- 在线表单的权限码是 `sys:online:list`（查询）和 `sys:online:edit`（新增、修改、删除）。
- 修改代码生成里的字段配置后，在线表单立即按新配置渲染，不需要重启。
- 普通用户在填报记录里只能看到自己提交的数据。

## 看效果

保存一份表单后，查看表单定义：

```sql
SELECT name, form_key, status FROM sys_form WHERE is_deleted = 0;
```

在线表单列出的表，与代码生成里已导入的表一致：

```sql
SELECT table_name, table_comment FROM gen_table WHERE is_deleted = 0;
```
