# 功能特性

后端自带下面这些功能，每项一页。用到哪个，点进去看怎么启用、怎么用。

## 流程与表单

<div class="ms-cards">

- [工作流](./workflow) 请假、报销这类多级审批，流程里可以插入 AI 预审节点。
- [表单](./form) 拖拽设计表单，或者直接对业务表做在线增删改查。
- [规则编排](./rule) 用 LiteFlow 把多个步骤编排成一条链。

</div>

## 任务与数据

<div class="ms-cards">

- [定时任务](./job) 在管理后台维护 PowerJob 任务，立即执行和查看执行记录。
- [报表](./report) 用内置数据集出图表。
- [对象存储](./storage) 本地、MinIO 和阿里云 OSS 三种存储，在管理后台切换。
- [单号规则](./serial-number) 按规则生成带日期的业务单号。
- [日志与审计](./log) 六种日志自动记录，操作日志能验出删改。
- [字典与参数](./dict) 固定选项用字典集中维护，参数在管理后台改完立即生效。

</div>

## 消息与搜索

<div class="ms-cards">

- [短信与邮件](./notify) 短信平台、邮件模板，以及一次发到多个渠道的通知接口。
- [站内信与公告](./message) 站内信和通知公告，经 WebSocket 实时推送。
- [全局搜索](./search) 顶栏搜索框联想用户、部门、角色和通知。

</div>

## 运维

<div class="ms-cards">

- [在线会话与登录客户端](./session) 查看在线终端并强制下线，按客户端设定令牌有效期和在线终端上限。

</div>

## 写在其他章节的功能

| 功能 | 能做什么 | 文档 |
| --- | --- | --- |
| 多租户 | 一个库里隔离多个租户，用套餐限定功能 | [多租户](/boot/tenant/) |
| 数据权限 | 按部门或本人过滤数据行 | [数据权限](/boot/datascope/) |
| 代码生成 | 从表结构生成前后端代码 | [代码生成](/boot/codegen/) |
| 开放平台 | 对外接口的签名、限流和 IP 白名单 | [开放平台](/boot/open-api) |
| 行为验证码 | 滑块、旋转、点选等五种验证码 | [行为验证码](/pc/captcha) |
| GIS 与地图 | 底图配置、地图工作台和空间分析 | [GIS 与地图](/pc/gis) |
| 埋点 | 采集页面访问、事件和错误，在看板里分析 | [埋点概述](/track/) |
| AI | 模型、对话、知识库和应用编排 | [AI 中心](/pc/ai-center)、[设计器](/pc/designer) |

GIS、埋点和 AI 是可选模块，不需要时可以在构建时去掉，见[后端概述](/boot/)。

## 谁能看到这些菜单

这一章各页提到的「系统管理」菜单，大多只对平台超管开放。原因见[租户与套餐](/boot/tenant/manage)的「平台级接口」一节。

用平台超管登录管理后台，展开「系统管理」，能看到「单号规则」「通知模板」和「我的消息」这些菜单项。
