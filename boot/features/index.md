# 功能特性

下表列出 mugsun 已有的功能，每项一页。已经有专门文档的功能直接链到原页面。

| 功能 | 能干什么 | 文档 |
| --- | --- | --- |
| 工作流 | 设计审批流程，发起、办理、退回和转办 | [工作流](./workflow) |
| 表单 | 拖拽设计表单，或直接对业务表做在线增删改查 | [表单](./form) |
| 规则编排 | 用 LiteFlow 把多个步骤编排成一条链 | [规则编排](./rule) |
| 定时任务 | 在管理台维护 PowerJob 任务，立即执行和查看日志 | [定时任务](./job) |
| 报表 | 基于内置数据集出图表 | [报表](./report) |
| 对象存储 | 本地、MinIO、阿里云 OSS 三种存储，运行时切换 | [对象存储](./storage) |
| 短信与邮件 | 短信平台、邮件模板和统一通知模板 | [短信与邮件](./notify) |
| 站内信与公告 | 站内信、通知公告，经 WebSocket 实时推送 | [站内信与公告](./message) |
| 单号规则 | 按规则生成带日期的业务单号 | [单号规则](./serial-number) |
| 全局搜索 | 顶栏搜索框联想用户、部门、角色和通知 | [全局搜索](./search) |
| 行为验证码 | 滑块、旋转、点选等五种验证码 | [行为验证码](/pc/captcha) |
| GIS 与地图 | 底图配置、地图工作台和空间分析 | [GIS 与地图](/pc/gis) |
| 埋点 | 采集页面访问、事件和错误，看板分析 | [埋点](/track/) |
| AI | 模型、对话、知识库和应用编排 | [AI 中心](/pc/ai-center)、[设计器](/pc/designer) |
| 多租户 | 一库多租户、套餐 | [多租户](/boot/tenant/) |
| 数据权限 | 按部门或本人过滤数据行 | [数据权限](/boot/datascope/) |
| 代码生成 | 从表结构生成前后端代码 | [代码生成](/boot/codegen/) |
| 开放平台 | 对外接口的签名、限流和 IP 白名单 | [开放平台](/boot/open-api) |

GIS、埋点和 AI 是可选模块，不需要时可以在构建时去掉，见[后端概述](/boot/)。

本章各页里提到的「系统管理」菜单，大多只对平台超管开放。原因见[租户与套餐](/boot/tenant/manage)的「平台级接口」一节。

## 看效果

用平台超管登录管理台，展开「系统管理」菜单，能看到本章各页提到的菜单项，例如「单号规则」「通知模板」和「我的消息」。
