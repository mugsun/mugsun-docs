# AI 中心

AI 中心是管理后台里和大模型有关的一组页面，用来配模型、对话、建知识库和搭 AI 应用。

这一页先列出有哪些页面，再说明怎么配好第一个模型，以及怎么让模型按知识库里的资料回答。

## 有哪些页面

点顶部导航的「AI 中心」，左侧菜单分成四组。

| 分组 | 页面 | 用来做什么 |
| --- | --- | --- |
| AI 应用 | 机器人助手 | 和模型对话，可以带上一个知识库 |
| AI 应用 | 机器人应用 | 新建 AI 应用并在画布上编排，见[设计器](/pc/designer#ai-应用编排) |
| AI 应用 | 知识库中心 | 上传资料，供对话和 AI 应用检索 |
| AI 应用 | 智能体问数 | 用一句话查数据库，结果可以做成仪表盘 |
| AI 工具 | 大模型配置 | 登记对话、向量、图像和音频模型 |
| AI 工具 | 提示词配置 | 保存常用的提示词 |
| AI 工具 | MCP 工具箱 | 登记 MCP 工具，供 AI 应用调用 |
| AI 工具 | 向量库配置 | 登记存放向量的库，自带一个内置的 |
| AI 工具 | 数据库配置 | 登记智能体问数要查的数据库 |
| AI 工具 | 消息渠道 | 登记企业微信、钉钉和飞书的机器人地址，用来发通知 |
| AI 运维 | 超级密钥 | 给外部系统发密钥，用来调用兼容 OpenAI 的对话接口 |
| AI 运维 | 对话记录 | 查看和导出对话 |
| AI 运维 | 账单记录 | 按天看 token 用量和费用 |
| AI 运维 | 配额与预警 | 设置每月的 token 和费用上限 |
| 智能体集合 | 思维导图等七个页面 | 填好要求后直接生成内容 |

- 能看到哪些页面由角色的菜单权限决定。
- 每个页面还有自己的权限码，例如大模型配置是 `ai:model:list`。
- 在其他页面点屏幕右侧的「AI」也能提问，见[工作台的 AI 助手](/pc/workbench#ai-assistant)。

## 从配模型到第一次对话

<div class="ms-steps">

### 添加模型

打开「AI 工具 → 大模型配置」，在「对话模型」页签点「添加新模型」，填好下面几项后保存。

| 项 | 怎么填 |
| --- | --- |
| 模型名称 | 列表里显示的名字，不能和已有的重复 |
| 提供商 | 选一个后自动填上它的默认 Base URL |
| Base URL | 模型服务的接口地址，以 `http://` 或 `https://` 开头 |
| 模型标识 | 调用时传给模型服务的模型名，例如 `deepseek-chat` |
| API Key | 模型服务发的密钥 |

### 测试到「已激活」

保存时后端会试着调用一次模型。调通了卡片上显示「已激活」，没调通显示「未激活」。

没调通时检查 Base URL 和 API Key，改好后点卡片上的「测试」再试。

### 设为默认

点卡片上的「设为默认」。只有「已激活」的模型能设为默认，每种类型只有一个默认模型。

### 开始对话

打开「AI 应用 → 机器人助手」，点「新对话」，输入问题后按 Enter 发送。

</div>

- Base URL 是内网或本机地址时保存会被拒绝，要先放行，见 [AI 出站白名单](/boot/configuration#ai-出站白名单)。
- 修改 Base URL 时，API Key 和 Secret Key 要重新填。
- 「输入单价」和「输出单价」按每千 token 多少元填，账单记录按它算费用。
- 对话时不选模型就用默认模型。没有默认模型时，用最新的一个已激活模型。
- 向量模型、图像模型和音频模型在各自的页签里添加，向量模型还要填「向量维度」。

## 让模型按资料回答

知识库把上传的资料切成小段。提问时先找出相关的几段，再和问题一起交给模型。

![知识库详情页的「资料」页签，列出每份资料的分段数和向量状态](/screenshots/pc/ai-knowledge-detail.png)

<div class="ms-steps">

### 新建知识库

打开「AI 应用 → 知识库中心」，点「新建知识库」，填好名称后保存。其他项可以先用默认值。

### 上传资料

点知识库卡片进入详情页，在「资料」页签点「上传资料」，选好文件后点「上传并向量化」。

这份资料的「向量状态」变成「已向量化」后就可以检索。

### 做一次命中测试

切到「命中测试」页签，输入一个问题后点「命中测试」，下面列出找到的分段和分数。

### 在对话里使用

打开「机器人助手」，在顶部的「知识库（可选）」里选这个知识库再提问。

回答下面的「引用」列出用到的分段。

</div>

::: warning 先确认向量模型可用
知识库没选向量模型时用默认的向量模型。没有可用的或者调用失败时，后端改用一个本地算法生成向量。

这时「向量状态」照样显示「已向量化」，但向量检索的效果很差。先到「大模型配置」把向量模型测试到「已激活」。
:::

应用编排里的「知识库」节点用的也是这里的知识库，见[设计器](/pc/designer#ai-应用编排)。

### 知识库的设置

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| Embedding | 第一个向量模型 | 用哪个向量模型把资料和问题转成向量 |
| 检索模式 | 混合检索 | 见[检索模式](#retrieval) |
| TopK | 6 | 一次最多找回几段，可以填 1 到 20 |
| 最低分 | 0.35 | 向量检索时不要相似度低于它的分段，可以填 0 到 1 |

知识库卡片上的「测试」不用进详情页就能做一次命中测试。

### 支持的文件 {#files}

| 类型 | 扩展名 | 怎么处理 |
| --- | --- | --- |
| 文档 | `pdf` `docx` `pptx` | 后端用 Apache Tika 取出文字 |
| 文本 | `txt` `md` `markdown` `csv` `json` `log` `html` `htm` | 浏览器读出文字后提交 |

- 单个文件默认不超过 20MB。
- 文档会检查文件头，内容和扩展名对不上的被拒绝。
- 不支持 OCR。扫描件取不出文字，「向量状态」显示「失败」，原因写在「失败原因」列。
- 一份资料默认最多切成 5000 段。超过时上传被拒绝，把「分段长度」调大后再传。
- 这两个上限的配置项见[配置说明](/boot/configuration#知识库资料上传上限)。

### 分段 {#segments}

上传对话框里有三项决定资料怎么切。

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 分段策略 | 段落 | 选了 `.md` 文件时自动换成「Markdown 标题」 |
| 分段长度 | 800 | 一段最多多少个字符，可以填 100 到 4000 |
| 重叠 | 80 | 相邻两段重复的字符数，最多 500，并且不超过分段长度的一半 |

| 分段策略 | 怎么切 |
| --- | --- |
| Markdown 标题 | 遇到标题行就切，一个标题和它下面的内容是一段 |
| 段落 | 遇到空行就切 |
| 定长 | 每满「分段长度」个字符切一次 |
| 按行 | 一行一段 |

- 按标题、空行或行切出来的一段超过「分段长度」时，再按定长切开。
- 「重叠」只在按定长切的时候起作用。
- 「分段」页签列出每一段的内容，可以按资料筛选。
- 有权限 `ai:kb-seg:edit` 时可以修改一段的内容，保存后自动重新向量化。
- 停用一段后，关键词检索不再用它。向量检索目前不看这个开关，仍然可能找到它。
- 「资料」页签的「重分段」按上传时的设置重新切一遍，手工改过的分段会被替换。

### 向量化

上传时已经自动向量化，一般不用再操作。「向量化」页签用来补做和重做。

- 「开始向量化（仅待处理）」只处理还没成功的分段。
- 「全量重建」把启用的分段全部重新生成一遍向量，换了向量模型后用它。
- 向量化是同步执行的，中途不能暂停，需要权限 `ai:kb-seg:vector`。

### 检索模式 {#retrieval}

![命中测试的结果，列出分数、来源和分段内容](/screenshots/pc/ai-knowledge-hit-test.png)

| 检索模式 | 怎么找 |
| --- | --- |
| 混合检索 | 向量和关键词两边都找，再把两份结果合并排序 |
| 向量检索 | 把问题转成向量，找意思最接近的分段 |
| 关键词 | 把问题拆成词，找包含这些词的分段 |

- 「最低分」只管向量这一边，关键词找到的分段不受它限制。
- 混合检索时一边没有结果，就只用另一边的结果。上图就是只有关键词这一边有结果。
- 「来源」列写着这一段是哪一边找到的，`vector` 是向量，`keyword` 是关键词。
- 「来源」后面带 `+boost`，表示又按问题里的词出现了多少调过一次分数。
- 数据库没装 pgvector 扩展时，「向量状态」显示「关键词」，这时只有关键词检索能用。

### 用接口上传 {#upload-api}

页面上传资料用的是下面两个接口，其他系统也可以直接调用。

| 接口 | 传什么 | 请求格式 |
| --- | --- | --- |
| `POST /system/ai/knowledge/asset/upload-file` | `pdf` `docx` `pptx` 文档 | 表单上传，字段是 `knowledgeId` 和 `file` |
| `POST /system/ai/knowledge/asset/upload` | 一段文字，或者一个文档的下载地址 | JSON |

```json
{
  "knowledgeId": 1001,
  "fileName": "员工手册.txt",
  "contentText": "请假不超过三天的，由部门负责人审批。",
  "segmentType": "paragraph",
  "segmentLength": 800,
  "segmentOverlap": 80
}
```

- 两个接口都要登录，并且有权限 `ai:kb-asset:upload`。
- 把 `contentText` 换成 `fileUrl`，后端会去下载这个地址的文档再解析。
- 三个分段参数都可以不传，不传时按定长切，长度 500，重叠 50。

| `segmentType` | 对应页面上的 |
| --- | --- |
| `markdown` | Markdown 标题 |
| `paragraph` | 段落 |
| `length` | 定长 |
| `newline` | 按行 |
| `symbol` | 页面上没有。按 `segmentSymbol` 给的分隔符切，分隔符最长 16 个字符 |

## 打开已经删除的详情页

用旧链接打开一个已经删除的知识库时，页面只显示「知识库不存在或已删除」、编号和返回按钮。

下面四个带编号的页面都是这样处理的：

| 页面 | 地址 | 返回到 |
| --- | --- | --- |
| 知识库详情 | `/ai/knowledge/detail/:id` | 知识库中心 |
| 问数配置 | `/ai/dataset/config/:id` | 智能体问数 |
| 问数对话 | `/ai/dataset/run/:id` | 智能体问数 |
| 仪表盘设计 | `/ai/dashboard/design/:id` | 智能体问数 |

仪表盘设计页的编号可以是仪表盘的，也可以是问数的。两个都查不到才显示不存在。

## 关闭 AI 模块

| 在哪里关 | 怎么关 | 效果 |
| --- | --- | --- |
| 后端环境变量 | `MUGSUN_AI_ENABLED=false`，重启后端 | AI 接口返回 404，菜单里不再有 AI 中心 |
| 系统参数 | 把 `ai.module.enabled` 设为 `false` | 不用重启，效果同上 |
| 管理后台构建变量 | `VITE_ENABLE_AI=false`，重新构建 | 管理后台不再包含 AI 中心和 AI 助手 |

开关取值的完整规则见架构页的[两层开关](/guide/architecture#模块装配-两层开关)。
