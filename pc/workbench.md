# 工作台

工作台是登录后看到的第一个页面，汇总了统计数字、待办和通知。屏幕右侧边缘是 AI 助手的入口。

![登录后看到的工作台](/screenshots/pc-workbench.png)

## 工作台上有什么

| 区域 | 内容 |
| --- | --- |
| 统计卡片 | 用户、部门和角色的数量，以及我的待办数。点卡片进入对应页面 |
| 用户状态分布 | 启用和停用的用户各有多少 |
| 租户用户数 | 每个租户的用户数 |
| 我的待办 | 等我处理的流程任务，最多显示 6 条 |
| 通知公告 | 最近 6 条通知，标题旁是未读数 |
| 更新日志 | 当前版本和最近 6 条更新记录 |
| 快捷入口 | 常用页面的链接，每个人可以自己挑选 |

- 统计数字和用户状态分布只统计当前租户。
- 「租户用户数」只对平台超级管理员显示，或者在查看全部租户时显示。
- 图的横轴是租户名称。平台租户 `000000` 没有名称时显示为「平台」。

## 更新日志卡

卡片顶部是当前版本，取自构建时管理后台 `package.json` 的 `version`。

下面按发布时间倒序列出最近 6 条记录，每条有日期、类型、版本号和标题。

| 看到的内容 | 含义 |
| --- | --- |
| 「未升级」标签 | 这条记录的版本号比当前版本新 |
| 「有新版本 vX」 | 列表里有比当前版本新的记录，vX 是其中最高的版本 |
| 「查看更新日志 ↗」 | 在新标签页打开 mugsun-pc 仓库的 `CHANGELOG.md` |
| 错误提示和「重试」 | 记录加载失败。当前版本不依赖接口，照常显示 |

- 版本号要写成 `1.2.3` 这样的三段，可以带 `v` 前缀。
- `1.x`、`1.2` 这类写法不参与比较，这条记录不显示「未升级」标签。
- 错误提示里的错误编号是这次请求的 `X-Trace-Id`，可以拿它到后端日志里查。
- 断网时请求没有到达后端，后端日志里查不到这个编号。

记录在「系统管理 → 更新日志」里维护，需要 `sys:changelog:manage` 权限。

卡片的数据来自 `GET /system/changelog/recent`，登录后就能读取，不受菜单权限和租户套餐限制。

## 快捷入口

点快捷入口右上角的「编辑」，勾选要放在工作台上的页面，再点「保存」。

- 候选页面共 16 个，只列出当前账号能打开的。
- 没有配置过时，显示默认的 6 个。
- 配置按用户保存在后端，换浏览器或换电脑登录都还在。

## 第一次登录时的设置提示

第一次登录时，右上角设置图标下方会弹出一个气泡，提示可以在这里换主题、开启顶栏菜单。

- 点「知道了」、点页面任意位置、打开设置面板，气泡都会收起。
- 8 秒内没有操作，气泡也会自己收起。收起后不再出现。
- 窗口宽度不超过 640px 时不弹。账号需要先修改密码时也不弹。

## AI 助手 {#ai-assistant}

屏幕右侧边缘有两个小标签，上面是「AI」，下面是「帮助」。点「AI」打开 AI 助手抽屉。

AI 助手属于可选的 AI 模块，要先在 [AI 中心](/pc/ai-center)配置模型。

### 提问

- 在输入框里按 Enter 发送，按 Shift+Enter 换行。生成过程中，发送按钮变成停止按钮。
- 输入框下方可以选模型和知识库。抽屉较窄时，这两项收进「设置」按钮。
- 新对话会显示 4 个示例问题，点一下就填入并发送。
- 还没有配置模型时，抽屉顶部会有提示。有模型管理权限的账号可以点「去配置」。
- 回复里的代码块带语言名和复制按钮。

### 回复出错时

出错的那条回复下方会显示错误提示和「重试」按钮。

重试得到的回复替换原来那一条，提问不会在历史里重复出现。

### 历史对话

点抽屉顶部的标题打开历史对话，按「今天」「7 天内」「更早」分组，可以搜索。

每条对话可以重命名、导出、清空消息和删除。标题右侧依次是新对话、全屏和关闭。

### 宽度和键盘

| 项目 | 说明 |
| --- | --- |
| 默认宽度 | 560px |
| 调整宽度 | 拖动抽屉左边缘，范围是 420–800px，调整后的宽度会记住 |
| 全屏 | 点顶部的全屏按钮。窗口宽度不超过 640px 时始终全屏 |
| 打开后的焦点 | 在输入框里 |
| Esc | 关闭抽屉，焦点回到「AI」标签 |
| Tab | 依次经过顶部按钮、消息区、输入框和发送按钮 |

用户消息的复制按钮平时是隐藏的，用 Tab 移到它上面时才显示。

### 抽屉加载失败时 {#drawer-load-failed}

抽屉的内容在第一次打开时才加载。超过 15 秒没有加载完，按失败处理。

- 加载失败时，抽屉里显示错误提示和「重试」按钮。
- 连续失败 2 次，页面会自动刷新一次。失败的是样式文件时，第一次就刷新。
- 这种情况常见于刚发布了新版本，旧文件已经被替换，刷新后就能加载到新文件。
- 自动刷新最多一次。刷新后还是失败，就停在错误提示上，要检查网络后再重试。
- 抽屉关闭以后不会自动刷新，正在填写的表单不受影响。

不管抽屉处在加载中、加载失败还是正常使用，右上角的关闭按钮和 Esc 都能关闭它。

## 窄屏下的变化

窗口宽度不超过 640px 时，几处界面会调整：

| 位置 | 变化 |
| --- | --- |
| 右侧的「帮助」和「AI」标签 | 缩成半透明的细条 |
| 机器人助手页 | 改为单栏，会话列表默认收起，点左上角的「会话」展开 |
| 埋点的「用户细查」 | 时间范围框占满整行，只显示到分钟 |
| 地图页右下角的状态条 | 只显示坐标和地名，不显示操作提示 |

## 切换页面时取消请求

切换到另一个页面时，上一页还没返回的请求会被取消，旧数据不会填到新页面里。

被取消的请求不弹提示，也不会在控制台报错。写新页面时不用为取消单独写 `catch`。
