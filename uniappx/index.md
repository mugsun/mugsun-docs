# ms-ui（uni-app x）

面向 **uni-app x** 的组件库，对外名 **ms-ui**，easycom 前缀 `ms-`。源码仓：[mugsun/mugsun-uniappx-ui](https://github.com/mugsun/mugsun-uniappx-ui)（私有）。

本站文档默认中文；组件页右下角手机框会 iframe 嵌入 H5 演示（需把 HBuilderX Web 导出产物放到 `public/demo/`）。
