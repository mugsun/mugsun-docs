# 报错速查

本页收录启动日志、迁移和接口返回里常见的报错。报错原文取自 boot、core、pc 主干的源码，每条写明原因和处理办法。

报错里带变量的部分用 `…` 表示，例如锁定的分钟数、字段名。

## 接口返回的状态码

后端的接口都返回统一结构 `{"code":…,"msg":…}`。下面这些 `code` 来自 core 的 `ResultCode`。

### 400 操作失败

```text
操作失败
```

请求参数类型不对、缺少必填参数，或请求体不是合法的 JSON 时，返回 HTTP 400 和这条提示。

请检查请求参数和请求体的格式。参数校验不通过时，`msg` 会换成字段上配置的校验提示。

### 400 数据已存在

```text
数据已存在，请勿重复提交
```

插入或更新触发了唯一约束，例如重复的账号、编号。这条提示不带字段名，具体字段在服务端 WARN 日志里。

请换一个没有用过的值再提交。这类错误不写入错误日志表。

### 401 请求未授权

```text
请求未授权
```

没有带登录令牌，或令牌已过期、已被踢下线。管理台收到后会退出登录，并提示「未授权访问，请重新登录」。

请重新登录。令牌只存在当前标签页，新开标签页也要重新登录。

### 403 没有访问权限

```text
没有访问权限
```

当前角色没有这个接口要求的权限标识或角色。

请让管理员在「角色管理」里给当前角色勾选对应的菜单或按钮权限。

### 403 没有接口的访问权限

```text
没有接口「…」的访问权限。请让管理员在接口权限中把该路径授给当前角色
```

这个接口配置了接口权限规则，而当前角色没有被授予该路径。

请按提示在「接口权限」里把该路径授给当前角色。

### 403 平台级资源

```text
仅平台超管可访问平台级资源
```

普通租户的账号访问了只对平台开放的功能，例如定时任务、报表、存储配置。

请用平台租户 `000000` 下的超级管理员账号登录后再操作。

### 404 资源不存在

```text
资源不存在
```

请求的路径不存在，常见于地址拼错，或者对应的模块没有启用。

请核对接口路径。GIS、AI 等模块关闭时，它们的接口也不存在。

### 405 请求方法不允许

```text
请求方法不允许
```

用错了 HTTP 方法，例如该用 POST 的接口发了 GET。

请按接口文档使用正确的方法。

### 500 服务器内部异常

```text
服务器内部异常
```

后端出现了未处理的异常。具体原因只写在服务端日志里，日志里有一行「系统未捕获异常」和完整堆栈。

请按响应头里的 traceId 到服务端日志查找对应的堆栈。boot 还会把这条错误写入「错误日志」。

## 验证码

验证码的错误都是 HTTP 200，`code` 是下面的业务码。业务码定义在 boot 的 `CaptchaCodes`。

### 40010 验证已过期

```text
验证已过期，请重新验证
```

验证码题目或验证通过后拿到的 `captchaToken` 已经过期。

请重新取题并完成验证。

### 40011 验证未通过

```text
验证未通过，请再试一次
```

拖动位置、旋转角度或点选顺序不对。为防止探测，所有失败都返回同一条提示。

请重新完成验证。

### 40012 尝试次数过多

```text
尝试次数过多，请稍后再试
```

同一来源短时间内验证失败太多次，触发了限流。

请等一会儿再试，响应的 `data` 里会带需要等待的时间。

### 40013 请先完成安全验证

```text
请先完成安全验证
```

验证码已开启，但登录、注册或发送验证码的请求没有带 `captchaToken`。旧前端仍调用已移除的 `GET /auth/captcha` 时也会出现。

请先走 `/auth/captcha/challenge` 和 `/auth/captcha/verify` 拿到 `captchaToken`，再放进请求体。

升级说明见[后端升级指南](/boot/upgrade#移除旧的数字图形验证码)。

### 40014 当前无需安全验证

```text
当前无需安全验证
```

当前租户关闭了验证码，前端却仍然去取题。

前端应先调用 `GET /auth/captcha/config`，按返回结果决定是否显示验证码。

### 40015 未启用无障碍验证方式

```text
未启用无障碍验证方式
```

用键盘方式取题，但租户没有启用滑块或旋转题型。键盘方式只支持这两种题型。

请在租户的验证码设置里至少启用滑块或旋转中的一种。

### 40016 验证方式暂不可用

```text
验证方式暂不可用，请联系管理员
```

租户启用的题型全部不可用，例如只启用了图标点选，但图标清单缺失。

请在租户的验证码设置里再启用一种题型，或补齐图标资源。

## 登录与账号

### 账号或密码错误

```text
账号或密码错误。请核对账号和密码后再登录
```

账号不存在或密码不对。为防止探测账号是否存在，两种情况返回同一条提示。

请核对账号和密码。连续输错会触发锁定。

### 账号已锁定

```text
账号已锁定，请 … 分钟后再试
账号已锁定，请联系管理员解锁
```

连续输错密码达到安全策略设定的次数后，账号被临时锁定。管理员手动锁定时提示联系管理员。

请等锁定时间过去再登录，或让管理员在「用户管理」里解锁。

### 账号已停用

```text
账号已停用，请联系管理员
```

账号被管理员停用。

请让管理员在「用户管理」里把账号改为启用。

### 登录已失效

```text
登录已失效，请重新登录
```

当前会话已经失效，例如令牌过期或被踢下线后又调用了需要登录的接口。

请重新登录。

### 租户账号数已达上限

```text
租户账号数已达上限（…），请联系管理员开通
```

新建用户时，租户下的账号数已经达到租户设置的上限。

请让平台管理员在「租户管理」里调高这个租户的账号上限。

## 启动

以下报错出现在启动日志里，应用会直接退出。

### 未配置 SM4 字段加密密钥

```text
未配置 SM4 字段加密密钥 MUGSUN_SM4_KEY，拒绝启动；本地开发用 dev profile（设 mugsun.crypto.sm4-local-key-file）
```

没有配置字段加密密钥。

本地开发时加上 `--spring.profiles.active=dev` 启动，会自动生成本地密钥文件。

生产环境请用 `openssl rand -hex 16` 生成密钥，配置到 `MUGSUN_SM4_KEY`。

### SM4 密钥格式不对

```text
MUGSUN_SM4_KEY 格式不对：须为 32 位 hex、解码后 16 字节的标准 base64，或过渡期的 16 字符旧写法；不补零不截断，拒绝启动
```

密钥长度或编码不对。

请改为 32 位 hex，例如用 `openssl rand -hex 16` 生成的值。

### SM4 密钥解不开已有数据

```text
MUGSUN_SM4_KEY 解不开库里已有的加密数据（…），拒绝启动。可能是换了密钥没迁移，或旧部署配的是 32 位 hex / 24 位 base64（旧版只取前 16 个字符）：请按文档「迁移」设 MUGSUN_SM4_OLD_KEY_LEGACY_PADDED=true 跑 Sm4KeyMigrationTool，或填回原来的密钥
```

启动自检时，现在的密钥解不开库里已经加密的字段。通常是换了密钥但没有迁移数据。

请填回原来的密钥。确实要换密钥时，按提示跑 `Sm4KeyMigrationTool` 迁移数据。

### 接口加密密钥等于旧内置默认值

```text
MUGSUN_API_KEY 等于已删除的旧内置默认值，拒绝启动：请换成新密钥（openssl rand -hex 16），或删掉该配置让系统自动生成
```

没配 `MUGSUN_API_KEY` 不再报错，会自动生成密钥。

详见 [core 0.1.0 → 0.2.0](/guide/upgrade/core-0-2-0)。

配了旧的内置默认值会被拒绝：删掉这项让系统自动生成，或用 `openssl rand -hex 16` 换一个。

多实例要用同一个密钥。

### 生产环境缺少初始口令

```text
生产环境必须注入初始口令（环境变量 MUGSUN_INIT_PASSWORD 或配置 mugsun.security.init-password），禁止使用内置默认口令启动
```

用 `prod` profile 启动，但没有配置初始口令，仍在用内置的默认口令。

请配置 `MUGSUN_INIT_PASSWORD`，再启动。

### 生产环境缺少 SM2 传输密钥

```text
strict-keys 模式：未注入 SM2 传输密钥（MUGSUN_SM2_PRIVATE_KEY/MUGSUN_SM2_PUBLIC_KEY），拒绝启动
```

`prod` profile 会打开 `strict-keys`，SM2 传输密钥必须注入。

审计签名密钥没配时不再拒绝启动，会自动生成到 `~/.mugsun/audit-sign-sm2.key` 并打 WARN。

请按提示配置对应的密钥对环境变量。

### 本地文件签名密钥

```text
prod 开启了本地存储直出（x-file-storage local-plus enable-access=true），必须配置 mugsun.file.local-access.sign-secret（MUGSUN_FILE_SIGN_SECRET，至少 32 字符）
mugsun.file.local-access.sign-secret 至少需要 32 个字符
```

用本地存储提供下载时，需要一个签名密钥来生成下载链接。

请配置不少于 32 个字符的 `MUGSUN_FILE_SIGN_SECRET`。多实例要用同一个值。

### 生产环境不能用内存验证码

```text
mugsun.captcha.store=memory 不能用于 prod profile，请改为 redis
```

内存存储只在单个实例内有效，生产环境不允许使用。

请删掉 `mugsun.captcha.store=memory`，或改为 `redis`。

### 缺少前端地址

```text
未配置 mugsun.web.front-url（环境变量 MUGSUN_FRONT_URL），无法跳转 OAuth 同意页
```

开放平台的 OAuth 授权需要跳转到管理台的同意页，但没有配置管理台地址。

请把 `MUGSUN_FRONT_URL` 设为管理台的完整地址，例如 `https://admin.example.com`。

## 数据库迁移

### V7 升级中止

```text
V7 升级中止：sys_user 有 … 组同租户重复手机号（未删除用户），手机号唯一索引建不了。…
```

只出现在 openGauss 和达梦。库里有同一租户下重复的手机号，唯一索引建不了。

请按[同租户重复手机号](/boot/upgrade#同租户重复手机号)查出并处理重复，再重新执行迁移。

### V11 升级中止

```text
V11 升级中止：sys_tenant 有 … 个租户编号被重复使用（含已删除行），全量唯一索引建不了。…
```

租户编号被重复使用过，包括已删除的租户。

请按[后端升级指南](/boot/upgrade)查出并处理复用的编号，再重新执行迁移。

## 管理台提示

管理台收到 HTTP 错误时，显示下面这些提示，文案在 pc 的 `src/locales/langs/zh.json`。

业务失败时，管理台直接显示后端返回的 `msg`。

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 未授权访问，请重新登录 | 后端返回 401 | 重新登录 |
| 禁止访问该资源 | 后端返回 403 | 让管理员给当前角色授权 |
| 请求的资源不存在 | 后端返回 404 | 核对地址，确认模块已启用 |
| 服务器内部错误，请稍后重试 | 后端返回 500 | 按 traceId 查服务端日志 |
| 网关错误，请稍后重试 | 网关返回 502 | 确认后端已启动、反向代理地址正确 |
| 服务暂时不可用，请稍后重试 | 网关返回 503 | 后端在重启或过载，稍后再试 |
| 网关超时，请稍后重试 | 网关返回 504 | 检查慢接口，或调大代理超时 |
| 网络连接异常，请检查网络连接 | 请求没有收到任何响应 | 检查网络、后端地址和跨域配置 |
