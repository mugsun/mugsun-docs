# Core Overview

[mugsun-core](https://github.com/mugsun/mugsun-core) ships the BOM and a few starters (Web, MyBatis, …) shared by boot and other modules.

- Most apps start from [boot](/en/boot/).
- Before building boot, clone this repo as a **sibling** and run `mvn clean install -DskipTests` (not on Maven Central yet).
- Starter lists and coordinates follow the repo README.
