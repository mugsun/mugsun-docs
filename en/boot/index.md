# Boot Overview

[mugsun-boot](https://github.com/mugsun/mugsun-boot) is the runnable backend: JDK 21, Spring Boot 3.5, optional modules (core / track / gis / ai / server).

Open source. Microservices edition is listed as **cloud · planned** on the home page.

See [Configuration](/en/boot/configuration) and [Security checklist](/en/boot/security-checklist). Details track the upstream README.
:::
