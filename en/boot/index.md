# Boot Overview

[mugsun-boot](https://github.com/mugsun/mugsun-boot) is the runnable backend: JDK 21, Spring Boot 3.5, optional modules (core / track / gis / ai / server).

| Module | Contents |
| --- | --- |
| core | System domain, auth, tenancy, … |
| track | Collect, replay, analytics APIs |
| gis | Maps / spatial capabilities |
| ai | AI orchestration (optional) |
| server | Runnable assembly shell |

Open source. Microservices edition is listed as **cloud · planned** on the home page.

Shortest path: [Getting started](/en/guide/getting-started). See [Configuration](/en/boot/configuration) and [Security checklist](/en/boot/security-checklist).
