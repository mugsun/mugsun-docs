# Getting Started

Goal: one **docker compose** (or the documented equivalent) from an empty environment to an admin login.

## Prerequisites

- Docker / Docker Compose
- Access to [mugsun-boot](https://github.com/mugsun/mugsun-boot)

## Outline

1. Clone `mugsun-boot` and open the directory that contains `docker-compose.yml`.
2. Start dependencies and the app per the repo README (Postgres, Redis, etc.).
3. Open the admin UI (ports per README).
4. Sign in with the documented demo account, then **change the password immediately**.
5. Smoke-test a system list page; if track is enabled, verify with [First event](/en/track/first-event).

::: warning
Commands and default credentials always follow each repo’s README. This page will later collapse into a single copy-paste script and link to a public demo.
:::
