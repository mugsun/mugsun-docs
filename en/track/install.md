# Install

```bash
pnpm add @mugsun/track-web
# or npm / yarn
```

Point `endpoint` at your boot gateway. Do not double-append `/track/collect` if the URL already includes it. Pass `router` in Vue apps when possible for path templating.

Full options and framework samples follow the [mugsun-track README](https://github.com/mugsun/mugsun-track). For local pc wiring, use the `file:../mugsun-track` dependency (`pnpm setup:sdk` in the pc README).
