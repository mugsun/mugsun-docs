# First Event

Goal: see **at least one** event on the admin analytics view after wiring the SDK.

1. Finish [Install](/en/track/install).
2. Ensure boot’s track module is on and reachable (default profile `full` includes track; toggle with `MUGSUN_TRACK_ENABLED`).
3. Trigger a PV or custom event.
4. Confirm in the pc analytics UI.

::: tip Acceptance
A 2xx collect request and a visible event for your app. Menu labels follow the current pc version.
:::
