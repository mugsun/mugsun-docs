# Admin Overview

[mugsun-pc](https://github.com/mugsun/mugsun-pc) is the Vue 3 + TypeScript + Vite + Element Plus console for system admin, analytics, GIS, and AI screens.

- Menus and permissions come from the backend—not another feature wall.
- Optional modules (`modules/gis` · `modules/track` · `modules/ai`) are gated by `VITE_ENABLE_*`.
- UI base derives from [art-design-pro](https://github.com/Daymychen/art-design-pro) (MIT)—retain NOTICE when redistributing.

See [Development](/en/pc/development). For a running backend, start with [Getting started](/en/guide/getting-started).
