# Development

1. Install Node (per pc README) and pnpm.
2. Clone [mugsun-pc](https://github.com/mugsun/mugsun-pc), run `pnpm install`.
3. Point env vars at local boot.
4. `pnpm dev`.
5. Prefer `pnpm gen:api` (or equivalent) over hand-written `any`.

::: tip
English version is abridged; Chinese page + repo README are authoritative for script names.
:::
